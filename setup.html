📲 SMS Auto-Sync Setup

One-time setup, about 5 minutes. Open this page in Safari on your iPhone so you can copy values straight into the Shortcuts app. Your token never leaves this page — it is only sent to GitHub.

1Create a GitHub token

The token lets your iPhone post alerts to the inbox. The link below pre-selects the gist permission only. Scroll down on GitHub, tap Generate token, then copy the ghp_… value.

Open GitHub token page ↗
2Create your SMS inbox (secret Gist)

Paste the token here and this page will create a private Gist as your SMS inbox and connect it to the Budget app automatically.

3Build the Shortcut — just one action

Open the Shortcuts app → + → name it Forward ADCB SMS. Add one action: "Get Contents of URL".

URL — tap to copy, paste into the action
—

Tap Show More inside the action and fill in:

  • Method: POST
  • Headers: add two:
    • Key Authorization → value below
    • Key Accept → application/vnd.github+json
Authorization header value
—
⚠️ This contains your token. Don't screenshot or share it.
  • Request Body: JSON
  • Tap Add new field → choose Text
  • Key: body · Value: tap the variable token (coloured pill) → pick Shortcut Input

That's the whole Shortcut — just one action, one JSON field. Now make it automatic:

  1. Shortcuts → Automation tab → + → Message
  2. Message Contains: ADCB · leave From empty
  3. Select Run Immediately (iOS 17+) → choose Forward ADCB SMS
