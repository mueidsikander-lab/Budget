📧 Email Auto-Sync Setup

One-time setup, about 5 minutes. Open this page in Safari on your iPhone so you can copy values straight into the Shortcuts app. Your token never leaves this page — it is only sent to GitHub.

ADCB no longer sends SMS alerts. Before starting, switch your ADCB alert channel from SMS to Email in the ADCB app or website (Settings → Alerts/Notifications), so transaction alerts arrive in your Mail app instead.
1Create a GitHub token

The token lets your iPhone post alerts to the inbox. The link below pre-selects the gist permission only. Scroll down on GitHub, tap Generate token, then copy the ghp_… value.

Open GitHub token page ↗
2Create your email inbox (secret Gist)

Paste the token here and this page will create a private Gist as your email-alert inbox and connect it to the Budget app automatically.

3Build the Shortcut — two actions

Open the Shortcuts app → + → name it Forward ADCB Email. Add these two actions in order:

  1. "Get Details of Emails" — set the input to Shortcut Input, and choose detail Plain Text Content.
  2. "Get Contents of URL" — configured below.
URL — tap to copy, paste into the action
—

Tap Show More inside the "Get Contents of URL" action and fill in:

  • Method: POST
  • Headers: add two:
    • Key Authorization → value below
    • Key Accept → application/vnd.github+json
Authorization header value
—
⚠️ This contains your token. Don't screenshot or share it.
  • Request Body: JSON
  • Tap Add new field → choose Text
  • Key: body · Value: tap the variable token (coloured pill) → pick Plain Text Content (from the "Get Details of Emails" action, not "Shortcut Input")

That's the whole Shortcut. Now make it automatic:

  1. Shortcuts → Automation tab → + → Email
  2. Contains: ADCB · leave From empty (unless you want to restrict it to ADCB's sending address)
  3. Select Run Immediately (iOS 17+) → choose Forward ADCB Email
